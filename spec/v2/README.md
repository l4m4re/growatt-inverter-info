# Growatt Register Specification V2

This is the generated block-oriented product specification. `register-spec-v2.json` is the sole V2 machine-readable authority; every Markdown page is rendered from that same in-memory model. Blocks are primary and family pages are projections.

Applicability selects an existing block or declared range; it never creates a register definition. Legacy and non-V1.24 material is retained explicitly under `legacy_material`.

Generated indexes: `BLOCK_INDEX.md`, `PROTOCOLS.md`, `SEMANTIC_INDEX.md`, `blocks/`, and `families/`.
