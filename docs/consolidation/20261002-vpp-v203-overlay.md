# Growatt VPP V2.03 overlay

## Scope

The local `tmp/VPP_Protocol_V2.03.pdf` is a 39-page Growatt VPP protocol
document revised 2025-08-31. Its SHA-256 is
`928f398c0889b7afa58763acf849a35f329645a725f1e6cd4ce2afb4284218b3`.
The document explicitly includes `MIN 2500-6000TL-XH/XH2/XHE/XA` as DTC 5100.

The normalized overlay is
[`sources/vendor/growatt-vpp-v2.03-delta.json`](../../sources/vendor/growatt-vpp-v2.03-delta.json).
The matching consumer CSV is
[`Growatt_ModbusTCP/Protocols/growatt_vpp_protocol_v2.03_delta.csv`](../../../Growatt_ModbusTCP/Protocols/growatt_vpp_protocol_v2.03_delta.csv).

## Versioning rule

V2.03 is represented as a delta over the existing V2.01 source. The V2.01
rows remain the base source; the overlay contains only changed or newly
specified rows. This avoids silently replacing existing model alternatives or
claiming that every V2.03 row is populated by every MIN-XH firmware.

The overlay contains 27 rows:

- bypass value 9 for 30101;
- the revised 30160 range;
- 30209–30215 automatic/manual grid mode and active-power/AC-charge controls;
- 30250–30255 diesel-engine controls;
- 30301–30305 demand-management and peak-shaving controls;
- revised 30404–30406 SOC ranges;
- AC-charge-first value 2 for 30410;
- revised 30475 range and 30476–30477 TOU controls.

## Firmware status

The overlay is `SOURCE_ONLY`. ZABA22 has a static VPP holding-table route and
proven write cases for 30100, 30101, 30407–30410, but its recovered 30101
case accepts only values 0/1, not V2.03 bypass value 9. ALBA18 currently has
30000 constants in timing/index functions, not a proven VPP dispatch. Firmware
compatibility therefore remains a separate evidence claim and is not implied
by importing this source overlay.

```sh
python tools/import_vpp_and_firmware_analysis.py --no-consolidated
python tools/validate_spec.py
```
